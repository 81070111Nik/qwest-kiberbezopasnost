# Веб-квест «Интернет – территория безопасности»

**Для областного фестиваля «Воспитание и Интернет» (Гомельская область)**  
**Целевая аудитория:** учащиеся + родители (законные представители)

## Как запустить

1. Откройте файл `index.html` в любом современном браузере (Chrome, Firefox, Edge, Яндекс.Браузер).
2. Интернет для работы квеста **не требуется** (всё работает локально).
3. Прогресс сохраняется в браузере (localStorage).

Можно разместить папку на школьном сайте, Google Sites, или раздать архив учащимся.

## Структура

- **Зона 1.** Цифровой след + права/обязанности + Семейный цифровой договор
- **Зона 2.** Фишинг — распознавание признаков
- **Зона 3.** Социальная инженерия — разбор кейсов
- **Зона 4.** Атаки с использованием ИИ (дипфейки, голосовой фишинг)
- **Зона 5.** Правовая культура + памятка + карта действий семьи
- **Финал.** Сертификат КиберСтража + творческое задание

## Рекомендации классному руководителю

- Перед началом проведите короткий инструктаж (5–7 минут).
- Попросите родителей помочь с заданиями «Совместное задание».
- После прохождения проведите рефлексию в классе.
- Лучшие творческие работы можно представить на фестивале.

## Технические требования

- Современный браузер
- Рекомендуется ПК или планшет (на телефоне тоже работает)
